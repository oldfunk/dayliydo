# 伊辛磁畴 · 居里相变

一个纯 HTML/CSS/JS 的单文件网页：一块二维伊辛磁体，每个自旋只问四个邻居"翻转还是不翻转"。把温度推过居里点的那一刻，贯通的磁畴集体雪崩成热噪点。双击 `index.html` 即可离线运行，零外部依赖、零网络请求。

12 月主题「临界现象 · 相变」第 2 件。

## 一、为什么做这个

11 月的「涌现图案 · 局部规则」第 4 件（沙堆）收束后，12 月往下推一层——**临界**。Kuramoto（本主题第 1 件）证明的是"有序从耦合里自己走出来"；这一件要证明的是相反的方向：**有序会在一条精确可算的线上消失**。

二维伊辛模型是这件事最硬的标的，因为它的临界点是**解析已知**的（昂赛格 1944）：

    kTc / J = 2 / ln(1 + √2) ≈ 2.2691853

同类作品（HN 上的 ising-model.vercel.app、各类 Ising 玩具）大多停在"拖温度看变色"。本作的差异化是**两条**：

1. **序参量的选择本身就是一个知识点。** h=0 时有限尺寸系统的平衡态里正反磁畴等概率，`|m|` 会互相抵消而趋近 0——拿 `|m|` 当序参量在 T<Tc 反而看不出有序。所以主序参量用**最大连通磁畴占全格的比例**：它单构型稳定、不依赖系综平均，在 T<Tc 接近 1，在 T>Tc 跌到 0.1 量级。加外场 h≠0 显式打破对称后，`|m|` 才重新成为干净的序参量——页面把这条对照直接做出来了。
2. **相变不是被画上去的，是被热化出来的。** 页面每个温度点都真的跑 Metropolis 扫描，曲线上的每个点都是一次平衡（或亚稳）采样，配种子确定性，同参数逐格复现。

## 二、核心机制与技术点

### 模型与更新

- 二维方格，周期性边界，最近邻铁磁耦合 J=1，k_B=1。
- Metropolis 单自旋翻转：ΔE = 2·sᵢ·(Σ邻居 s + h)，按 min(1, e^{−ΔE/T}) 接受。
- 每次 sweep 遍历全部 N 个格点各尝试一次；接受率实时显示（Tc 附近约 0.16–0.58）。
- 确定性：mulberry32 种子 PRNG，初始构型与全部随机数流同源，同种子逐格复现。

### 序参量与测量

- **最大连通磁畴占比**：4 邻接 BFS，周期性边界，O(N)。T<Tc 时一个畴贯通全格（≈1），T>Tc 时碎成 0.1 量级的小团。
- `|m|` = |Σs|/N，h=0 时在 T<Tc 会因双畴抵消而偏低，页面同时显示并解释。
- 能量 E = −Σ⟨ij⟩ sᵢsⱼ / N − h·m（每自旋），比热 c = Var(E)/T² 由滑动窗口累积。

### 实现要点

- **像素级渲染**：自旋直接写 `ImageData`（每格 1 像素），再 `drawImage` 关闭平滑放大到显示尺寸。零逐格绘制开销，L=160 也不卡。
- **异步扫描**：升温/降温扫描用 `setTimeout` 分片推进，每片 200 sweep，UI 不冻结；带进度条与停止按钮。扫描预算随 L 缩放（`850·4096/L²`），把全程压在约 30 秒量级。
- **磁滞是真实物理**：从全铁磁出发升温、再从高温返回，两条支不重合的部分来自亚稳态（成核需要克服界面能）。页面把两支分色画出，不假装它们重合。
- **点击翻转整畴**：点画布任意处，翻转该点所在的整个连通磁畴——把"畴"作为可操作对象，而不是单自旋。

### 验证结果（无头断言，24 项全通过）

`node selftest.js`，模型层 + UI 层全绿：

- **基态**：全铁磁 L=8 时 E=−2.0000、|m|=1、最大畴=1；棋盘构型最大畴=1/N。
- **周期性边界**：每格 4 个不同邻居、邻居关系互为对称、角点含跨边界回绕。
- **两相**：T=0.5Tc 随机出发 2500 sweep 后 |m|=0.999；T=3.5Tc 有序出发后 |m|=0.027。
- **相变**：L=64、1200 sweep，T=0.9Tc 最大畴 0.949 → T=1.5Tc 0.234（差 0.715）。
- **能量**：E(0.5Tc)=−2.000 < E(3.0Tc)=−0.311。
- **外场破缺**：h=±1、T=0.5Tc 时 m=±1.000。
- **确定性**：同种子两次 120 sweep 后逐格完全相同（max|Δ|=0）。
- **点击畴**：全铁磁点一下翻 256/256；半畴点一侧只翻 128/256，|m| 由 0 变 1。
- **性能**：L=96 单 sweep 2.23 ms，满足实时交互预算。

## 三、怎么玩

- **拖温度**：T/Tc 从 0.20 到 3.00。低温看磁畴贯通，推到 1.0 附近盯着它雪崩。
- **加热 / 冷却**：一键 ramp 到 3Tc 或 0.3Tc，看相变两个方向。
- **扫描 T（升+降）**：自动跑 17 个温度点 × 2 支，把最大畴占比曲线画出来，直接读出转变点与磁滞回线。
- **外场 h**：从 0 拉到 ±1.5，看对称性被打破后 |m| 曲线变得干净、不再被双畴抵消。
- **初始构型**：全铁磁 / 随机 / 左右半畴。半畴用于观察一条畴壁在低温下变直、在高温下破碎。
- **晶格 L**：32–160。L 越大转变越陡、越接近精确 Tc（有限尺寸效应）。
- **点击画布**：翻转整个连通磁畴，手动制造或消灭一个畴。
- **导出 PNG**：把当前磁畴图存成图片。
- **快捷键**：`空格` 暂停/继续，`↑`/`↓` 调温度，`R` 重开，`S` 扫描。
