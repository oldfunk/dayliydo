# 战斗回合追踪器 · Initiative Tracker

TRPG 桌面游戏中的战斗回合管理工具，用圆形时间环可视化回合节奏，自动处理效果衰减与轮转。

## 为什么做这个

传统 TRPG 战斗追踪依赖纸笔或电子表格，地下城主需要手动记录每个角色的先攻顺序、HP、效果持续时间，容易出错且打断游戏节奏。本工具将这一过程自动化：添加角色后自动按先攻排序，圆形时间环直观显示当前回合剩余时间，效果持续自动衰减，让地下城主专注于叙事而非计算。

核心巧思在于**圆形时间环**——用 SVG 圆环的 stroke-dashoffset 动画替代数字倒计时，视觉上更直观，且与"回合"的循环概念天然契合。

## 核心机制

- **圆形时间环**：SVG 圆环动画显示回合剩余时间，自动轮转
- **效果衰减**：每个角色可添加持续 N 回合的效果，每回合自动 -1，归零移除
- **先攻排序**：角色按先攻值自动排序，高先攻先行动
- **HP 管理**：快速扣血，阵亡角色自动跳过
- **localStorage 持久化**：角色列表和设置自动保存

## 技术点

- 纯 HTML/CSS/JS 单文件，零外部依赖，file:// 直接打开
- SVG stroke-dashoffset 实现圆形进度环动画
- setInterval 100ms 精确计时
- localStorage 持久化角色数据
- 响应式布局，深色主题，中文界面

## 怎么玩

1. 在底部"添加角色"表单中输入名称、先攻值、 HP
2. 点击"开始"启动圆形时间环倒计时
3. 时间耗尽自动轮转到下一位角色
4. 点击"下一位"手动跳过当前角色
5. 点击"HP-"快速扣血，点击"+效果"添加持续效果
6. 效果每回合自动衰减，归零自动移除
7. 点击"重置"清空当前回合状态
