# 反应扩散 · 图灵斑图

## 为什么做这个（设计意图）

把 Alan Turing 1952 年提出的「形态发生」方程搬上屏幕：两种化学物质在一张网格上扩散并反应，斑点、条纹、迷宫从**局部规则**里自己长出来，而不是被画出来的。想让「涌现」这件事可被亲手推演：拖动鼠标涂种子、滑动 f/k 双参数，看图案如何从一种相变到另一种。

## 核心机制 / 技术点

- Gray-Scott 反应扩散：`u' = Du·Δu − u·v² + f·(1−u)`，`v' = Dv·Δv + u·v² − (f+k)·v`
- 200×200 网格，有限差分拉普拉斯，ping-pong 双缓冲 typed array，每帧跑 N 步
- V 浓度场映射为颜色；鼠标涂画直接改 U/V 初值
- 预设 (f,k) 组合对应斑点/条纹/迷宫/孔洞/珊瑚/混沌六种相

## 怎么玩

1. 打开 `index.html`（离线可用）。
2. 拖动鼠标在画布上涂种子；或点「随机种子」。
3. 滑动 f / k 观察相变；点预设按钮一键切换图案。
4. 暂停后涂画，再继续，看新种子如何长成。
