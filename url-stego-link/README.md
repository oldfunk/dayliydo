# URL 隐写链接

把秘密藏在 URL hash 中，生成一段看起来完全正常的链接，分享后别人点开页面会自动解码。

## 核心机制

- **零宽字符隐写**：用 4 个零宽度 Unicode 字符（U+200B, U+200C, U+200D, U+2060）当「墨水」，把二进制数据编码为肉眼不可见的字符。
- **URL fragment 承载**：将隐写内容附加到 `#` 后面，作为 URL fragment，浏览器允许 fragment 长度远超可见部分，用户只看到正常的地址。
- **自动解码**：页面加载时自动从 `location.hash` 读取隐写内容并解码，刷新后仍保持，只要链接不变，内容就不变。
- **密码加密**：可选 SHA-256 密码派生流密码加密，使隐写内容更难被识别或破解。

## 玩法

1. 打开 `index.html`。
2. 在输入框中输入要隐藏的秘密消息。
3. 可选输入密码进行加密。
4. 勾选「把密文附加到链接末尾」，点击「生成链接」。
5. 页面会显示一段看起来完全正常的链接，其中 `#` 后面包含零宽字符。
6. 复制链接发送给他人，对方打开后页面会自动解码并显示隐藏内容。
7. 解密端可选择是否输入密码。

## 技术细节

- 使用 4 个零宽字符：ZERO_WIDTH_SPACE、ZERO_WIDTH_NON_JOINER、ZERO_WIDTH_JOINER、ZERO_WIDTH_NO_BREAK_SPACE。
- 空格 → ZERO_WIDTH_SPACE；换行 → ZERO_WIDTH_JOINER；制表符 → 3×ZERO_WIDTH_JOINER；回车 → ZERO_WIDTH_JOINER；零宽字符 → ZERO_WIDTH_OMITTED。
- 帧结构：START（U+2060 U+200B U+200D）+ 16 位零宽长度头 + 载荷。
- 密码加密：先对消息做 SHA-256 校验并拼接到尾部，再用密码派生出的密钥流（基于 SHA-256 的流密码）逐字节异或加密，最后才做零宽编码。
- 纯 HTML/CSS/JS，零外部依赖，离线可用。
