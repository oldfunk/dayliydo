# 不在场证明 · 时间地点推演台

一个单文件的推理桌面：六个人、六个时段、六间屋子，你亲手排出一张「谁在哪一段时间在哪一间屋」的网格。
凶手是谁不由代码告诉你，由**你自己的裁定自洽与否**告诉你。

打开 `index.html` 即可离线运行。零依赖、零网络请求、无构建步骤。

---

## ① 为什么做这个

这是「推理桌面 · 罗生门」系列的第三件（前两件：真相账本、命运种子遭遇表）。

前两件解决的是「**证词之间互相打架**」和「**世界记住你的选择**」。这一件换一个轴：
不再比较证词与证词，而是把证词放到一个**物理世界里**去检验。

推理小说里最经典的一招是「不在场证明」——但绝大多数推理游戏把它做成了脚本化的点击找线索：
点对地方就吐出一句新台词，玩家其实没有在推理，只是在解锁。

这里换一种做法：

- **没有隐藏线索。** 六个人在六个时段的说辞一开始就全部摆在网格上，一屏看尽。
- **没有脚本。** 没有任何一句台词是「因为你点了某处才出现」的。所有信息静态存在。
- **唯一的谜面是可达性。** 每段时间只能待在相邻的一间屋。于是「他这一段说自己在这里、那一段说自己在那里」就不再是两句话，而是一道**能不能走得通**的题。

一句话说清它巧在哪：**凶手不是被找出来的，是被时间表和走廊挤出来的。**

## ② 核心机制 / 技术点

### 1. 约束传播：位掩码 × 不动点迭代

每一格（人 × 时段）不存一个「答案」，而存一个 **6 位掩码**——他在该时段所有仍可能所在的地点。
求解过程就是不断做交集：

- 初始：全 6 间屋都可能（掩码 `0b111111`）
- 铁证：该格掩码收成 1 位（例：白芷第五段只能在前厅）
- 你的裁定：采信 → 掩码 `∩` 他说的地方；推翻 → 掩码 `∩` 其补集
- **沿走廊传播**：某一格的掩码先按邻接表扩张，再与相邻时段求交
  （`S[t] ∩= expand(S[t-1])`、`S[t] ∩= expand(S[t+1])`，双向）
- 重复到不再变化（实测 4 轮内收敛）

于是「他不可能在那里」会自动顺着时间轴扩散开去。

### 2. 矛盾不是提示，是空集

如果某一格的掩码被清成 `0`，那意味着：**按你自己的裁定，这个人在这一段时间无处可去。**
这是硬矛盾，不是软提示。格子会当场变红、显示「无解」，并列出他前后两段分别在哪儿。

这带来一个反直觉但很爽的体验：**只要你错信一句谎话，那一整行会一起塌掉。**
因为谎话的位置与真话的位置隔着走廊，前后接不上——时间轴会把它从两端夹死。

### 3. 唯一解，且最优解只有一条

案卷经过离线穷举验证（`36` 格的全组合）：

- 最少只要**推翻 4 格**就能让整份判定站得住
- 推翻 4 格时，站得住的判定**有且只有一条**（不是若干条里挑一条）
- 这条唯一的判定，恰好只指向一个人

所以游戏有一个可证明的最优解：**一眼看穿 = 推翻 4 格**。多推翻一格不算错，只是绕远路。

### 4. 结构性诡计：阁楼锁死了凶手

真相用的不是「谁有动机」，而是一个纯结构事实——

> **阁楼只有书房一个入口，楼梯窄得只容一人。**

凶手第五段上了阁楼（被侍女撞见），所以第五段他必须在阁楼；
而阁楼只通书房，所以第四段他必须在书房。
可他偏偏说第四段自己在前厅——**他躲进阁楼的同时，也把自己钉死在了书房。**

这是他唯一的破绽，而且不来自任何人的证词，来自他自己选的那条退路。

### 5. 判定码：可分享的自洽性快照

`AG1.` 前缀 + base64url 编码的 JSON，只记录 36 个三态值与一个指认 id。
编码器与解码器都做了**严格校验**：前缀、版本号、数组长度、取值域（只允许 0/1/2）、
人物 id 是否已知——任何一项不符就整份拒绝，绝不静默降级成半个状态。

### 6. 其它工程细节

- 纯 ES5（`var` + 立即执行函数），无 `import`，`file://` 下直接跑
- **全程零 `innerHTML`**：所有节点用 `createElement` / `textContent` 构建，不存在注入面
- 深色 / 浅色跟随系统 `prefers-color-scheme`，响应式，窄屏侧栏自动落到网格下方
- 状态存 `localStorage`，刷新不丢；隐私模式下静默降级
- 六个时段的划分是设计过的：凶手那一段必须落在**正中间**，否则前后扩散到不了两侧

## ③ 怎么玩

1. 双击 `index.html`。左侧是网格：**行 = 人，列 = 时段**，格子里是他声称自己所在的地点（简称）。
2. 单击任意格子循环三态：**未决 → 采信 ✓ → 推翻 ✗**。
   格子下方那行小字会实时告诉你：按你现在的裁定，他那时还可能在哪儿。
3. 带下划线的格子是**铁证**（有人同时看见，点它会提示改不了）。其余全靠你判断。
4. 盯住右侧「矛盾」：一旦出现红格，说明你的裁定已经自相矛盾。点它可以直接跳到出事那一格。
5. 案子是：**柳宅命案**。老爷死在书房，案发时间 **22:20–22:40（第五段）**。
   右侧「案发时段」会实时算出：谁还能进书房。
6. 当你做到**没有矛盾、且案发时段恰好只剩一个人能进书房**时，在底部指认他，点「提交结案」。

### 想直接看答案

点「全部采信」——把六个人的话全当真。你会看到四个人的整行一起塌掉，那就是他们撒谎的地方。
（这是最快的理解方式，但不算你自己破的案。）

### 两条提示（想自己破案就先别看）

<details>
<summary>提示一：从哪儿下手</summary>

别去猜凶手。先找那些「说他没动过」的人——一段都没挪窝的人，只会有一个地方可以待在。
再顺着走廊往外看：谁的位置把他前后两段都钉住了？
</details>

<details>
<summary>提示二：四格都在哪一类</summary>

四个人撒了谎，但只有一个人的谎**同时**被他自己前后两段夹住。
其余三句谎话只是走不通，夹不死人。
</details>
