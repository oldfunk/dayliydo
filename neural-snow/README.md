# 神经雪 · 脉冲雪片 · Neural Snow

一台会自己长雪花的放电沙盘。雪花不是画出来的 —— 它是被脉冲打出来的。

双击 `index.html` 即可离线运行，零依赖、零网络请求。

## 一、为什么做这个

前面几件作品（共振沙盘、像素地图生成器）都在回答同一个问题：**不靠任何贴图、预设图案或人工绘制，一个系统能不能自己长出结构？**

共振沙盘长的是克拉德尼图（驻波节线），本件要长的是**雪花**。

雪花的麻烦在于：它太"眼熟"了。任何人都能一眼认出雪花该长什么样，于是生成出来的东西一旦不对就会立刻露馅 —— 长成一团实心块、长成一根针、长成乱糟糟的丝，全都不行。这类作品失败的典型原因不是"不够好看"，而是**它长出来的东西在物理上说不通**：雪花的分杈来自扩散限制，你拿一个"电势堆积 + 局部冻结"的启发式去凑，最后往往凑成一根针。

所以本件的核心命题定得很死：

> 必须用**扩散限制聚集（DLA）** 的教科书形式生长 —— 粒子从簇外一圈出发、做随机游走、碰到冰才粘住 —— 而不是"哪个格子电势高就往哪长"。

这样分杈才是**涌现**的：尖端暴露得多、截获的粒子就多，侧枝因为被挡住而"饿死"。不需要任何"分叉规则"，DLA 自己会分。

电势（放电）系统不参与生长，它是**雪花的"天气"**：脉冲在雪里传播、绕行、堆积、留下疤痕，同时负责可视化（放电蓝光）和再激活。生长与放电是两套独立但耦合的系统 —— 这是本件与前作"共振沙盘"的关键区别，也是它不会糊成一团的根本原因。

## 二、核心机制 / 技术点

### 2.1 生长：扩散限制聚集（DLA）

- 每步先算冰簇的**质心与半径**，然后从「簇外一圈」（半径 = 簇半径 + 14）的圆周上随机角度放出 `WALKERS`（默认 14）个粒子。
- 每个粒子做**四邻域均匀随机游走**（电势场**不参与**游走 —— 一旦让粒子顺着电势走，生长就退化成"往高电势长"，必然长成针或一团）。
- 一碰到冰（4 邻域有冰）就按粘附概率贴上去；没粘上就继续走（DLA 的"粘附概率 < 1"变体，长出来更密实）。
- 粒子步数上限是**自适应**的：`max(WALK_LEN, 6 × 环半径)`。这一点很关键 —— 环越大粒子要走的路越长，固定步数会让远处的粒子永远走不到簇上，生长会静默停住。
- 走出「kill circle」（环半径 × 2.2 + 8）的粒子直接丢弃重生，等价于经典 DLA 的"走出杀伤圈就重生"。
- 每步最多新冻住 `GROW_GAIN`（默认 6）格，控制生长节奏，让人眼看着它长。

### 2.2 放电：电势场 + 波相位

- `pot[]` 是电势场，`pha[]` 是相位（0 静息 / 1 充电 / 2 放电）。
- 电势超过阈值 `thresh` 的格子放电：电势推到 1，向 8 邻域广播脉冲，自身进入放电相。
- **放电相必须是瞬时的**：放电当帧就把相位清零。这是自测里专门盯的一条不变量（`phaTransience`）—— 一旦有格子连续两步都处在放电相，就是相位泄漏。
- 电势在冰面上**无法扩散**，波前只能绕行，绕行处局部电势堆积。刚长出来的枝因此更容易被再次激活 —— 侧向抑制。

### 2.3 疤痕与窒息

- 每次放电在冰面上留下疤痕（`frz[]`，上限 1.6）。疤痕越深的地方越难再被冻住（粘附概率打折）。疤痕**会随时间淡去** —— 否则"冻住阻力"只增不减，迟早变成负概率把生长彻底锁死（这是开发中真实踩到的 bug，已在自测中加断言防回归）。
- 若一整波放电的 4 邻域几乎全是冰（`free4 / (n1 × 4) < 0.06`），电势无处可去，这波被扑灭，计入"窒息"并在画布右下角红色闪光。

### 2.4 确定性与自测

- 同样的网格尺寸 + 同样的参数 = 同一颗雪。重建时把随机流复位（`rstate = 0x5f3a91`、`seedSeq = 0`）。
- 内置 13 项无头断言：`location.hash = "#selftest"` 触发，通过时页面标题变成 `SELFTEST PASS`。覆盖：重放确定性、随机流非常数、记账一致、电势值域、疤痕值域、生长有界、放电会发生且会结束、相位瞬时性、冰格一致、边界无相位泄漏、点击脉冲、点击产雪、渲染不抛错。

### 2.5 工程约束

- 纯 HTML/CSS/JS 单文件，普通 `<script>`（非 ES module，`file://` 下 CORS 会拦）。
- 零外部依赖、零 CDN、零 `fetch` / `XMLHttpRequest`。
- 网格是扁平 `Float32Array` / `Uint8Array`，二维坐标手算偏移（`OFF4` / `DX8` / `DY8`），避免每帧分配。

## 三、怎么玩

**界面**：左侧参数面板 + 右侧画布。画布上亮蓝是正在放电的格子，白是雪，暗灰是电势场（开"显示场"可见），橙色是疤痕。

**鼠标 / 触摸**

- 点击画布 —— 注入一个电脉冲，看波前绕开雪花传播。
- `Shift + 点击` —— 直接写雪（画一个圆盘冰面），用来手动"种"一颗雪。
- 拖动画笔 —— 持续注入脉冲。

**键盘**

- `空格` —— 暂停 / 继续
- `R` —— 重置（清空重长）
- `F` —— 切换显示场
- `H` —— 切换疤痕

**参数**

- 放电频率 / 放电半径 / 激活阈值 / 遗忘速度 / 扩散系数 —— 放电系统的性格
- 粘附概率（越低越松散）/ 生长偏好 / 种子数 / 核大小 / 风 / 画布分辨率 —— 雪花的性格
- 实时读数：雪片像素、累计雪片、放电次数、当前相位、每秒步数、窒息次数

**导出**：右上角保存 PNG。

## 四、参考

DLA 生长模型（Witten–Sander 1981）、扩散限制聚集的分形维数特性。电势/相位部分参考反应扩散与神经元脉冲耦合系统（FHN / Morris–Lecar 的简化形式），但本件只做可视化类比，不是生理模型。

同类可视化作品的常见做法是"用电势高低决定生长方向"，本件刻意避开 —— 那是本件在开发中失败了很多次之后换的路。
