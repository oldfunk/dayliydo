# 随机决策转盘

把纠结交给运气！自定义转盘选项，点中间按钮一键旋转，指针停下处即为今日定夺。

## 玩法
- **转动**：点击转盘中央「开始」按钮。
- **改选项**：双击右侧列表里的文字可修改内容。
- **加选项**：底部输入框输入后点「添加」（回车也行）。
- **删选项**：点选项右侧 `×`（至少保留 2 个）。
- **恢复默认 / 清空**：右侧两个按钮。
- 选项会自动存在浏览器本地（localStorage），下次打开还在。

## 特点
- 纯 HTML/CSS/JS，零依赖、零网络请求，离线双击 `index.html` 即用。
- 扇区配色自动循环，旋转带缓动动画，结果高亮显示。
- 结果与落点精确对应，纯随机、纯娱乐。

> 打开方式：直接双击 `index.html`，或浏览器拖入即可。
