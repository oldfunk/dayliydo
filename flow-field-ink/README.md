# 流线仪 · 噪声场寻路

## 为什么做这个（设计意图）

「涌现图案」系列的第三件。前两件（反应扩散、Langton 蚂蚁）都是离散格点上的局部规则，这一件换到**连续向量场**：一个由值噪声生成的流场，墨线不是被画出来的，而是被场推着走出来的。

核心命题是给「画线」加一条**可验证的约束**：粒子每走一步，先算当地的**散度**（divergence）——散度为负是汇聚区（水会流进来），才准落笔；散度为正（超过阈值）是发散区（源区），墨就断，粒子还会被加速冲散。于是画面上的疏密不是随机的：**墨迹只沿着排水结构收束**，源区自然留白。这不是「噪声的等高线」，而是这条约束下唯一允许的路径。

为了让人能亲手验证这条约束，面板里放了实时自检：位移方向与场方向的一致率、落笔点与断墨点的平均散度对比。约束成立时徽标变绿。

## 核心机制 / 技术点

- **周期性值噪声场**：lattice 大小 Kx×Ky 与画布像素一一对应（u = x/W·Kx），格点下标按模回绕，画布正好铺满整数个格子——场在左右、上下边界都严格连续（对边场角差 0.00000000）。粒子在环面上环绕时不会在接缝处跳变，这是「环绕」成立的前提。
- **散度凭证**：向量场 F = (cosθ, sinθ)，散度 div F = ∂cosθ/∂u + ∂sinθ/∂v，在噪声坐标（格）里求导，与格子大小无关。求导步长 0.01 格，远小于噪声最小波长（1/8 格），避免混叠（早期用 0.15 格时散度分布严重偏斜，就是混叠造成的）。
- **墨量经济**：每颗粒子带墨量 1。汇聚区落笔耗墨 0.006/步（约 167 步耗尽），发散区被冲散耗墨 0.030/步（约 33 步耗尽）。墨尽则死，步数耗尽或撞墙（环面下不会撞墙）也会死。
- **环面边界**：粒子从一边出去从另一边进来，流线不断，画面均匀铺满而不是往中间堆。
- **旋度模式**：勾选后对噪声取旋度得到无散场（div ≈ 0），流线变成闭合环流，与直接角度场形成对照——同一噪声，两种根本不同的流。
- **种子可复现**：mulberry32 + 置换表，同种子必得同一个场；「重新布场」随机换种子。
- **Canvas ImageData 整帧重绘**，墨色按墨量渐变，慢速消退（fade 0.03/帧）让旧线留下层次。

## 怎么玩

1. 打开 `index.html`（离线可用，零外部依赖）。
2. 「暂停/开始」控制运行；「洗掉墨水」清空画布与统计；「重新布场」随机换种子。
3. 单击画布任意位置，在该处撒一把新粒子。
4. 调「断墨阈值」：调低 → 源区变多，墨线断裂得更碎；调高 → 只有最强源区才断墨，线条更连贯。
5. 调「噪声格数」：格子越少，流线越粗犷；越多越细碎。
6. 勾选「旋度约束」看无散环流；勾选「显示场线背景」对照墨线与场方向。
7. 看右侧「自检」：徽标变绿说明方向一致率 100% 且落笔/断墨的散度分区成立。
