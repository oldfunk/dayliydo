# 新标签页弹球

在新标签页空白画布中玩弹球，游戏即页面本身，无额外 UI 干扰。

## 核心机制

- **游戏即画布**：整个新标签页就是游戏区域，进入即玩，无菜单/按钮/广告。
- **空格发射**：按空格发射球，挡板由鼠标或触摸控制。
- **撞砖得分**：击碎所有砖块即胜利，漏球则游戏结束。
- **零依赖**：纯 HTML/CSS/JS，零外部资源，离线可用。

## 玩法

1. 打开 `index.html`（或设为新标签页扩展）。
2. 点击「开始游戏」或按空格。
3. 用鼠标/触摸左右移动挡板，按空格发射球。
4. 击碎砖块得分，漏球则游戏结束，可重置再玩。

## 技术细节

- 碰撞检测：球与挡板/砖块/边界。
- 响应式画布：窗口大小变化时自动重算砖块布局。
- 状态管理：开始/进行中/游戏结束。
- 数据持久化：无（每局独立）。
