# 命运种子遭遇表 · Fate-Seeded Encounter Table

一个纯离线的单文件 TRPG 遭遇生成器。它的核心不是"随机"——随机表人人会写——而是**命运可复现 + 抉择会改变未来**。

## 一、为什么做这个（设计意图）

跑团主持人（GM）用随机遭遇表有两个长期痛点：

1. **不可复现。** 事后想回看"上次那条路上到底发生了什么"，或者想把一个精彩的遭遇序列分享给别的 GM，传统随机表做不到——掷过的骰子回不来。
2. **没有因果。** 传统遭遇表是纯均匀抽样：你战斗了十次，遇到强盗的概率和第一次一样。玩家的行为对世界没有任何影响，世界是死的。

本作把这两个痛点变成两个机制：

- **命运种子（seed）**：所有随机数来自一个字符串种子。相同种子 + 相同抉择序列 = 完全相同的遭遇链，在任何设备、任何时间都一致。
- **抉择权重（fate weight）**：每次你选择「战斗 / 交涉 / 潜行 / 回避」，都会永久改变五个类别（环境 / 生物 / 人物 / 事件 / 线索）的后续抽样权重，以及一个 0–10 的「危险度」。**战斗越多，路上越危险**——世界记住了你的行为。

一句话概括它巧在哪：**它把随机数表变成了一个状态机，而状态由玩家的选择推动；同时整个状态可以被压缩成一个几十字节的字符串，在别人机器上无损重放。**

## 二、核心机制 / 技术点

### 1. 确定性随机数流

- `xmur3(str)` 把任意字符串种子散列成 32 位整数；`mulberry32(a)` 用它生成可重现的伪随机序列。
- 初始化时用固定前缀 `dayliydo::encounter::` + 种子喂入，保证同一台机器之外也得到同一序列。
- 关键约定：**每次抽取恰好消耗 5 个随机数**（类别、条目、态度、细节、收获）。这个固定配额是重放能够对齐的根本——抽取次数与消耗量严格成正比。

### 2. 事件溯源式重放（不是快照）

状态里**只存 `{ seed, choices[] }`**，不存任何遭遇内容。

每次渲染时，`buildChain()` 从头开始：用种子重建 RNG 流，按抉择序列逐个重放每一次抽取和每一次权重变更，最后多抽一次作为"下一次遭遇"。

好处：

- 撤销、导入、刷新页面全都免费正确——因为它们都只是"改一下抉择序列然后重放"。
- 分享码极小。`ET1:可复现的命运|潜战交避` ——一个种子加四个汉字，就能在别人电脑上重建整条遭遇链。
- 天然抗篡改：不需要校验和，任何不一致都会立刻在重放结果里暴露。

### 3. 权重系统

- 五个类别各有基础权重 10，加上动态偏移（每个类别钳制在 −8 ~ +8）。
- 抉择影响：战斗 → 生物 +3 / 事件 +1 / 人物 −1；交涉 → 人物 +3 / 线索 +1 / 生物 −1；潜行 → 环境 +2 / 线索 +2 / 生物 −1；回避 → 环境 +3 / 事件 −1 / 人物 −2。
- 加权抽样用累积权重法，偏移为负的类别仍保留最低权重，因此**不会真正消失**，只是变得罕见——避免玩到后期世界塌缩成单一类别。
- 危险度 0–10，战斗 +2、交涉/潜行 −1、回避 −2，并实时改变颜色（绿 → 金 → 红）。

### 4. 界面

- 深色友好，响应式（窄屏下骰子卡自动堆叠）。
- 权重以实时条形图展示（左负右正的对称刻度），危险度有独立进度条——玩家能"看见"世界正在被自己改变。
- 内置遭遇表编辑器：可改标题、改权重、增删条目，保存进 `localStorage`，不影响默认表。
- 快捷键：`1–4` 抉择，`R` 重开，`Backspace` 撤销。
- 所有用户输入在写入 DOM 前经过 `esc()` 转义（`& < > " '`），编辑器与命运链均无 `innerHTML` 注入面。

### 5. 零依赖

单个 `index.html`，无 CDN、无网络请求、无构建步骤、无 ES module（避免 `file://` 下的 CORS 限制）。双击即可离线运行。

## 三、怎么玩

1. 双击 `index.html`。
2. 在「命运种子」里输入任意一句话（比如 `雾港的第七夜`），或点「随机种子」。
3. 阅读当前遭遇卡：类别、标题、描述，以及三枚 d6——**态度 / 细节 / 收获**。这三个是"展开提示"，用来即兴发挥而不是照本宣科。
4. 在「你的抉择」里选一个行动（或按 `1`–`4`）。注意上方权重条与危险度的变化——你正在塑造接下来的路。
5. 「命运链」会记录每一步。点「撤销上一步」或按 `Backspace` 回退。
6. 点「复制命运码」，把它发给朋友；对方粘进「复现这条命运」并回车，就会得到**逐字相同**的整条遭遇链。
7. 想用自己的世界观？展开「遭遇表编辑器」，改写条目和权重，点「保存为我的遭遇表」。种子 + 自定义表 = 你自己的随机世界。想还原点「恢复默认」。

### 建议的跑团用法

- 开团前把种子定为团名或战役名，整场战役的随机遭遇就有了统一"命运"，事后可完整复盘。
- 玩家做出重大决策后，把命运码写进跑团记录。半年后想重开这段路，粘回去即可。
- 把命运码当作"世界线的 ID"来用：同一个种子下不同抉择序列 = 同一个世界的不同分支。
