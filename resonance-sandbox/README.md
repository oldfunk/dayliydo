# 共振沙盘 · 双板模态叠加器

一个自包含的单文件网页作品：两块振动板叠加同一组驻波模态，
沙粒在板面上被「弹」到节点线上，堆出可预测、可验证的共振图案。

零外部依赖、零网络请求、零 CDN，双击 `index.html` 即可离线运行。

---

## ① 为什么做这个

前面几件作品（真相账本、不在场证明、圆桌证词、像素地图）都是**离散**的：
状态是格点、是排列、是掩码。这件换到**连续场**上。

灵感来自克拉德尼板（Chladni plate）：一块绷紧的金属板被弓弦摩擦共振时，
撒上去的细沙会自己退到节线（nodal line）上，排出几何花纹。
这个现象之所以好看，是因为**它不是被画出来的，是被物理挤出来的**——
沙子没有智能，它只是每次弹跳都损失能量，最后停在"最不晃"的地方。

所以这件作品的核心命题是：**能不能让一个纯前端的连续场模拟器，
不靠任何贴图、任何预设图案，光靠模态叠加 + 沙粒能量耗散，
长出一张和真实克拉德尼板同构的图？**

为了不让它变成"换皮的颜色渐变"，我做了两件反直觉的事：

- **不显示瞬时位移**，只显示时间平均的包络场。真实沙粒响应的是能量（振幅平方），
  不是瞬时位移——瞬时位移在一周期内平均为零，沙子不可能被它推动。
- **显示场和沙粒势能场必须是同一张网格**。很多同类作品"画的是显示的，
  跑的是另一套"，两者会悄悄错位。这里共用一张 `ENV_GRID`，
  所以"你看到的暗线"和"沙粒真正停下的地方"严格是同一个位置。

## ② 核心机制 / 技术点

### 模态叠加（modal superposition）

板面位移写成一组矩形板驻波模态的线性组合：

```
w(x,y,t) = Σ_k a_k(t) · sin(m_k π x) · sin(n_k π y)
```

模态表用 `f = 1 + 0.15·(m² + n²)` 生成，天然带出**简并**：
`(2,1)` 与 `(1,2)` 频率完全相同、形状正交——这是叠加出干涉图样的前提。
边界条件 `φ = 0` 由 `sin` 自动满足，不需要额外处理。

### 受迫阻尼谐振子（解析稳态解）

每个模态坐标是一个独立的 `ÿ + 2ζωn ẏ + ωn²y = F·sin(Ωt)`。
我没有用数值积分，而是**直接写稳态解析解**：

```
A = F / sqrt((ωn² − Ω²)² + (2ζωnΩ)²)
θ = atan2(2ζωnΩ, ωn² − Ω²)
a(t) = A·cos(Ωt − θ)
```

这样做有三个好处：振幅严格有界（不会爆）、共振峰真实存在（不是拟合出来的）、
以及**能量收支可以闭式核对**——每帧算一次「驱动注入功率」和「阻尼耗散功率」，
两者必须相等。这不是装饰，是一个持续运行的自检。

> 踩过的坑：第一版把循环频率 `f` 和角频率 `Ω = 2πf` 混在同一个式子里，
> 失谐项差了 `(2π)² ≈ 39.5` 倍，所有模态振幅都塌到 0.005，
> 整块板渲染成"全是节点"。是无头测试跑出来的，不是看出来的。

### 沙粒：各向异性耗散

板面做垂直简谐振动 `z(t) = z₀·cos(Ωt)`，沙粒交替处于**接触**与**弹跳**。
法向约束力 `N` 必须随振动变化，于是摩擦力方向取决于相位：

- **法向（垂直于等势线）**：每次接触都把沙粒推回平衡位置，
  一阶平均力 = `−k·d`，`d` 是该点到节点线的垂直距离 → **线性回复，压向节点线**。
- **切向（沿等势线）**：法向力的涨落幅度在节点线上最小，
  等效为沿等势线的弱扩散 → 沙粒**沿线排开**，形成连续的线而不是一个点。

关键约束：**切向不能有恒定推力**。对称性保证它的均值恒为零，
硬加一个常量切向力只会让沙粒绕圈而不是聚成线。
这一条我删掉过又加回来过，是整件作品里最容易被"优化"掉的东西。

势能取 `V = |归一化包络场|`，其极小值就是节点线。
势能梯度用半解析差分，每个沙粒每帧只需 3 次采样。

### 按住点：约束投影

按住板面任意一点 = 给模态振幅加一条线性约束 `Σ a_k·φ_k(pin) = 0`。
做法是**把振幅向量投影到该约束的超平面上**（最小范数修正）：

```
a_k ← a_k − (Σ a_j c_j) · c_k / (Σ c_j²),   c_k = φ_k(pin)
```

这样合成场在按住点严格为零（数值验证到 `1e-10`），
且对原有振型的扰动最小——节点线被"拉"过该点，但其余形状尽量保持。
右键按住则作用于板 B。

### 性能

- 形状数组按模态组合预绑定成连续内存，内层循环零 Map 查找、零字符串键
- 包络场每帧只算一次（`computeEnv`），显示与沙粒共用同一张网格
- 调色板预计算成 1024 级 LUT，渲染路径上不再有 `Math.pow`
- `computeEnv` 用「模态在外、网格在内」的循环顺序，写回同一条缓存线

实测（V8，Node 原生基准，非跨上下文）：整帧 **14.5 ms**，
其中 `computeEnv` 3.6 ms、`renderField` 0.96 ms、12000 粒沙 9.5 ms。
约 69 fps；树莓派 3B 上可把沙粒数调到 6000 保持流畅。

## ③ 怎么玩

**界面**：左侧是板面画布（沙粒 + 包络场），右侧是参数面板。

**基本操作**

- **拖动「激振频率」** —— 这是主要玩法。扫过模态谱时，
  离哪个模态近，哪个模态就被点亮，图案随之重组。
  默认值正好落在 `(1,1)` 的共振点上，打开就能看到清晰的十字节线。
- **拖动「相位差 Δφ」** —— 两块板之间的相位。转 90° 时干涉图样会从
  "叠加"变成"正交"，节点线位置整体移动。
- **按住画布拖动** —— 在板 A 上打一个支点，节点线被拉过该点。
  **右键按住**作用于板 B。
- **「模态组合」四个预设** —— 前两组是简并对（同频异形，
  叠加出稳定干涉），后两组是双频（错开，图案随时间呼吸）。
- **勾选「节点线」** —— 用白线描出 `|包络场| < 0.045` 的等值线，
  和沙粒实际堆积的位置对照着看。
- **勾选「振动向量」** —— 显示每个采样点的位移方向与幅度。

**值得试的几件事**

1. 把相位差从 0° 慢慢转到 180°，看节点线怎么"流动"
2. 在 `(2,1)+(1,2)` 简并预设下按住板中心——节点线会被强行拉过中心
3. 把「锐度」调低，包络场会显出更多中间调，能看清节点线是怎么"收窄"的
4. 关掉沙粒（数量拖到 0）只看场，再打开——对比"场的节点"和"沙粒的落点"

**面板读数**

- `模态贴合度` —— 当前驱动频率与两块板主模态的接近程度
- `沙粒` —— 当前粒数（数量可调，不增不减）
- `能量收支` —— 驱动注入 vs 阻尼耗散，**两者应当相等**；
  若长期偏离说明稳态解或积分出了问题
