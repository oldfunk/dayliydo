# Langton 蚂蚁 · 规则涌现

## 为什么做这个（设计意图）

Langton 蚂蚁是「涌现」最干净的示范：一只蚂蚁在黑白格子上走，规则只有两条——白格右转涂黑、黑格左转涂白。跑上 ~10000 步后，蚂蚁会**自发**进入一条斜向的周期性「highway」，而规则里从未写过「走直线」。本作把规则表开放给用户编辑（转向 L/R/S/U + 新颜色），让人亲手看到：**图案不是被画出来的，是规则跑出来的**，换几格规则就换一种世界。

## 核心机制 / 技术点

- Turmite（多状态蚂蚁）：网格 Uint8Array，每格颜色 0..N-1；蚂蚁读颜色 → 按规则表转向并重涂，再前进一格。
- 规则表可编辑（L 左转 / R 右转 / S 直行 / U 掉头 + 新颜色），颜色数 2–8，环面/撞墙两种边界。
- Highway 检测：追踪最近转向序列，识别周期 2/4 的重复模式，实时标出进入 highway 阶段。
- 预设 5 套经典规则（highway / 方块螺旋 / 三角迷宫 / 混沌团 / 条纹道）+ 随机规则 + 规则编码复制/粘贴。
- 规则编码：形如 `R1L0` 的紧凑字符串，可复制分享、粘贴复现。
- Canvas ImageData 整帧重绘，steps/帧可调（1–20000），导出 PNG。

## 怎么玩

1. 打开 `index.html`（离线可用）。
2. 点「开始/暂停」控制运行；「单步」逐格观察。
3. 滑动「步/帧」加速；切换预设规则看不同涌现。
4. 编辑规则表或点「随机规则」，观察图案变化；进入 highway 时右上徽标变绿。
5. 点「导出 PNG」保存当前图案。
