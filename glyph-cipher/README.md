# glyph-cipher — 同形字密写

隐写家族第四作，**机制本质不同**于前三作（零宽插入式）：
- 零宽三部曲 = **插入不可见字符**，文本长度增加，易被清洗工具剥离
- 同形字密写 = **替换为视觉同形字**，文本长度**不变**，肉眼不可辨，复制粘贴天然存活

## 核心机制：同形字替换隐写

- **映射表**：26 个常用拉丁字母 → 视觉极度相似的西里尔/希腊字母（如 `A`→`А` U+0410, `a`→`а` U+0430, `e`→`е` U+0435, `o`→`о` U+043E…）
- **编码**：把秘密文本按映射表逐字符替换，得到「看起来完全一样」但码点不同的同形字文本
- **载体模式**：可选载体文字，按位替换载体中可映射的字符，超出部分追加；无载体时直接输出同形字文本
- **可选加密**：同 `invisible-cipher` 的 SHA-256 流密码风格 XOR + Base64，密码错误即乱码
- **解码/检测**：扫描文本中的所有同形字码点，高亮显示、还原拉丁字母、可选解密
- **可视化面板**：实时粘贴检测，逐字高亮同形字，显示替换率统计

## 玩法

1. **编码隐藏**：输入秘密 + 可选载体 + 可选密码 → 生成同形字隐写文本 → 复制发给对方（微信/邮件/代码注释/Markdown 任意纯文本场景）
2. **解码检测**：粘贴收到的文本 + 可选密码 → 自动高亮所有同形字、还原明文
3. **可视化对照**：随时粘贴任意文本，实时看到哪些字符被替换了，附完整映射表（含 Unicode 码点）

## 与前作的承继关系

| 维度 | invisible-cipher / titlerun-game / url-stego-link | glyph-cipher |
|------|--------------------------------------------------|--------------|
| 隐写类型 | **插入式** 零宽字符 | **替换式** 同形字 |
| 文本长度 | 增加（每字符插入 1–2 个零宽） | **完全不变** |
| 视觉差异 | 完全不可见 | 肉眼**不可辨**，但码点不同 |
| 抗清洗 | 弱（很多平台自动剥离零宽） | **强**（正常字符，不被清洗） |
| 适用场景 | 需要大容量、不介意长度变化 | 短消息、代码注释、用户名、Markdown、终端、任何纯文本 |
| 核心巧思 | Unicode 零宽字符作「墨水」 | Unicode **同形字冲突**作「伪装」 |

> 这是隐写系列的**范式转折**：前三作证明「藏在看不见的缝隙」，本作证明「藏在看得见的假象里」。

## 技术细节

- 单文件 `index.html`，零依赖、零 CDN、离线可用
- 映射 22 个拉丁字母（含大小写），覆盖高频字母 `a c e i o p x y` 等
- 优先西里尔（与拉丁字形最接近），希腊作备选
- 密码加密：PBKDF2 风格派生密钥 + XOR 流密码 + Base64，同 `invisible-cipher` 算法兼容
- `file://` 双击即用，现代浏览器完美渲染同形字

## 设计意图

「最好的隐藏不是不可见，而是**伪装成最普通的样子**」。

零宽隐写像用隐形墨水写在纸背面——一照灯（清洗工具）即现；同形字隐写像把字写在纸正面，但每笔都换成了长得一模一样的异体字——肉眼读不出差别，机器才能查出「这字不对劲」。

这是隐写术从「利用不可见空间」到「利用视觉等价类」的跨越。
