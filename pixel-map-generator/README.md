# 像素地图生成器

种子确定性的程序生成地图工具。输入任意字符串作为种子，同一 seed 永远生成同一张地图。支持三种地形模式，可导出 PNG 图片或 JSON 数据供游戏开发使用。

## 为什么做这个

游戏策划和原型开发中经常需要快速生成地形参考图。现有工具要么太重（Tiled Map Editor），要么不保证可复现（纯随机）。这个工具的核心设计意图是：**种子即设计**——策划可以把自己想要的关卡特征编码成 seed，分享给开发者在不同工具链中复现同一张地图。

## 核心机制

- **种子确定性**：任意字符串经 FNV-1a 哈希后驱动 mulberry32 伪随机数生成器。同 seed 输出完全一致，可跨平台复现。
- **元胞自动机洞穴**：经典 CA 算法——随机填充后迭代平滑，细胞根据周围 8 格的墙数量决定自身状态。多次迭代后形成自然洞穴纹理。
- **距离场岛屿**：以地图中心为原点计算径向距离场，叠加正弦噪声模拟海岸线，阈值切割后生成有机形态的岛屿。
- **递归回溯迷宫**：标准 DFS 迷宫生成，在 (2N+1) 网格上打通墙壁，保证全连通且无环。
- **生态着色**：按模式自动切换配色——洞穴=岩壁/水蓝、岛屿=沙地/绿地、迷宫=紫墙/通路。

## 怎么玩

1. 在种子栏输入任意文字（如 `dungeon-42`），点击「生成地图」。
2. 切换地形模式（洞穴 / 岛屿 / 迷宫）观察不同算法的输出特征。
3. 调整密度和平滑迭代参数，微调地形开敞程度。
4. 选择「网格叠加」辅助像素级定位，或「生态着色」快速预览风格化效果。
5. 导出 PNG 用于美术参考，导出 JSON 用于程序加载。

## 技术要点

- 纯 HTML/CSS/JS 单文件，零外部依赖，file:// 直接打开。
- Canvas + ImageData 直接操作像素，image-rendering: pixelated 保证清晰像素风。
- 连通区域计数使用 BFS 洪水填充，实时统计空地率和区域数。
- 响应式布局，移动端可用。
