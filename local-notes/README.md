# 本地便签 · Markdown 笔记

一个零依赖、可离线运行的 Markdown 笔记工具。左侧写 Markdown，右侧实时预览；内容自动保存在浏览器 `localStorage`，关闭页面也不丢。

## 玩法
- 在左侧编辑区输入 Markdown（支持标题、粗体、斜体、行内代码、列表、引用、链接、分割线、表格、代码块）。
- 顶部工具栏一键插入常用语法；若先选中文字再点「粗体 / 斜体 / 代码 / 链接」会直接包裹选区。
- 右下角实时显示字符数与词数；状态灯亮起表示已保存。
- 「导出 .md」把当前笔记下载成 Markdown 文件；「清空」一键重置（有二次确认）。

## 注意
- 数据仅存于本机浏览器，不上传任何服务器。换浏览器 / 隐私模式 / 清除站点数据会丢失，重要笔记请点「导出 .md」备份。
