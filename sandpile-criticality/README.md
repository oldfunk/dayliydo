# 沙堆临界 · 自组织临界沙盘

一个纯 HTML/CSS/JS 的单文件网页：只有两条局部规则，分形沙堆与无标度的崩塌规模分布全部从规则里长出来。双击 `index.html` 即可离线运行，零外部依赖、零网络请求。

## 一、为什么做这个

11 月主题「涌现图案 · 局部规则」的第 4 件（加做）。同主题前三件分别是：反应扩散（连续 PDE 场）、Langton 蚂蚁（离散图元）、流线仪（噪声场 + 粒子）。这一件回到最离散的元胞自动机，但带上一个**可验证的统计量**——崩塌规模分布。

网络上绝大多数"沙堆"作品（落沙玩具）是同一类东西：沙粒受重力下落、堆积成丘，看着解压，但没有任何可推演的结构。BTW 沙堆模型完全不同，它是统计物理里"自组织临界"（self-organized criticality）的开山模型：

- 规则只有两条，没有任何一处代码知道"图案"该长什么样；
- 分形堆形、连锁崩塌、幂律分布，都是规则的涌现性质；
- 它可以被验证：平均高度应稳定在 2.0～2.2，崩塌规模分布应趋近幂律。

所以这个作品的核心命题不是"看起来像沙堆"，而是**让你亲眼看着一条幂律从几十万条局部规则里长出来**，并且能自己动手验证它。

## 二、核心机制与技术点

### 规则

1. 格子高度 `h >= T` 时崩塌：`h -= T`，把 T 粒分给相邻格子。
   - BTW 模式（默认）：T 固定为 4，确定性分给上下左右四格。
   - Manna 模式：T 可调（3～8），T 粒随机分给相邻格（可重复命中同一格）。
2. 边界敞开：分到界外的沙粒永久逸出。系统靠"投放—崩塌—逸出"达到稳态。

### 实现要点

- **栈驱动崩塌**：只在高度"跨过"阈值的瞬间把格子入栈；出栈时若仍 `>= T` 则再次入栈。重复入栈由出栈时的条件判断兜住，不会重复崩塌。
- **高度必须用 32 位整数**。这是开发中踩到的真坑：大崩塌时一个格子在等待出栈期间可能累积数百粒，若用 `Uint8Array` 会按模 256 回绕，凭空吞掉沙粒——实测因此丢过 512 粒（正好两次回绕），并且破坏了中心堆的四向对称性。换成 `Int32Array` 后守恒律与对称性才同时成立。
- **统计预热**：堆内沙粒（`grains - lost`）少于格子数 N 时不记录崩塌——那是"堆在生长"的瞬态，混进直方图会让分布变形。达到 N（约每格 1 粒）后自动开始记录，界面显示"预热中"徽章。
- **投放协议**：只有崩塌栈清空（完全放松）才投放下一波。这样每次崩塌都干净地归属一次投放，直方图才是物理上可解释的。把"每波投放粒数"设为 1，得到的就是教科书式的单粒崩塌分布。
- **每帧预算制**：每帧有一份"崩塌格次"预算，栈空就用预算投放并推进崩塌。崩塌波前因此既可慢放逐格观察，也可全速推进。
- **渲染**：`ImageData` + `Uint32Array` 直接写像素，离屏画布整数倍放大，`image-rendering: pixelated` 保证放大后依然锐利。崩塌中的格子带衰减高亮，波前清晰可见。
- **直方图**：横轴按 log2 分桶（桶 b 代表规模 `[2^b, 2^(b+1))`），纵轴 log10，临界态下应呈近似直线下降。
- **确定性**：投放与 Manna 重分布都走同一种子驱动的 PRNG（mulberry32），同种子逐格复现。

### 验证结果（无头断言，全部通过）

模型层 23 项断言 + 视图层 16 项冒烟断言，均通过。关键数据：

- **守恒律**：`sum(h) == grains - lost` 在 BTW 与 Manna 下均精确成立。
- **对称性**：中心投放 2 万粒后，沙堆四向严格对称。
- **临界态**：128×128、单粒投放 6 万波后，平均高度 **2.111**（2D BTW 临界值约 2.125）。
- **幂律**：崩塌规模分布（log2 分桶）单调下降——
  `2751, 2089, 1678, 1327, 1133, 971, 860, 843, 763, 634, 618, 574, 441, 297, 141, 42`
  最大崩塌规模 102570 格次，共记录 15162 次崩塌。
- **对比实验**：把"每波投放粒数"调成 20，多次崩塌合并，分布会变成 U 形——这正是"为什么要单粒投放"的现场演示。

## 三、怎么玩

- **投放模式**：中心（看圆锥形分形堆生长）/ 随机（看系统自我组织到临界态）/ 关闭（只手动）。
- **每波投放粒数**：默认 1。设为 1 时直方图是教科书式单粒崩塌分布；调大可以观察分布如何变形。
- **每帧最多波数**：控制投放节奏，默认 30。
- **每帧崩塌格次**：调小（比如 10）可以一格一格看崩塌波前扩散；调大则全速推进。
- **模型**：BTW 确定性 / Manna 随机。切到 Manna 后阈值 T 可调。
- **网格尺寸**：96 / 128 / 160 / 192，切换会重建沙盘。
- **手动投放**：点击或拖动画布，在任意位置制造一次局部崩塌（笔刷 1×1 / 3×3 / 5×5）。
- **暂停 / 单步**：空格暂停，暂停后点「单步」每次推进一帧；快捷键 `空格` 暂停、`S` 单步、`R` 重置。
- **导出 PNG**：把当前沙盘存成图片。
- **种子**：同种子可复现同一局；「换一批」随机换一个种子。
