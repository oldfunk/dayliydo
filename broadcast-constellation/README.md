# 星图共振 · 多标签页同步星座

一个零依赖、可离线运行的「跨标签页共享星座」小工具。打开多个标签页，在任意标签页点击画布添加星星，所有标签页实时同步——同一片星空，所有窗口共享。

## 核心机制

- **Broadcast Channel API**：利用浏览器原生的 `BroadcastChannel` 实现同源标签页之间的零服务器通信。`file://` 协议下多个同文件标签页即构成同源，自动共享消息通道。
- **共享星图状态**：星星坐标、名字、连线关系通过消息广播同步到所有标签页。每新增一颗星星，立即广播给其余标签页。
- **自动星座连线**：距离小于阈值的星星自动连成星座线，距离越近线越亮，营造「星空图」的视觉叙事。
- **持久化**：星星数据存于 `localStorage`，刷新页面不丢。
- **全标签页重置**：点击「重置星图」会广播清空命令，所有标签页同步清空。

## 玩法

1. 打开 `index.html`，再打开 2-3 个相同文件的标签页。
2. 在任一标签页点击画布空白处 → 新增一颗星星。
3. 立刻在其他标签页看到这颗星星「瞬移」过来。
4. 点击已有星星 → 弹出命名框，输入名字后回车确认 → 所有标签页同步显示名字和连线。
5. 星座线自动生成在附近的星星之间——名字越多，星座图越丰富。
6. 「重置星图」按钮会清空所有标签页的星星（需二次确认）。
7. 「清空视图」仅清空当前标签页的本地视图（不广播）。

## 技术细节

- 纯 HTML/CSS/JS，零外部依赖、零 CDN、零网络请求，`file://` 双击即用。
- `BroadcastChannel` 原生 API，无需 WebSocket 或服务器。
- Canvas 2D 渲染，`devicePixelRatio` 适配高清屏。
- `localStorage` 持久化，刷新不丢。
- 消息广播节流（50ms），防止高频同步风暴。

> 打开方式：直接双击 `index.html`，或浏览器拖入即可。建议同时打开多个标签页体验「星图共振」。
