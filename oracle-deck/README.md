# 神谕卡牌 · Oracle Deck

TRPG 桌面游戏中的命运判定工具，用三级递进神谕系统替代传统骰子，为地下城主提供更叙事化的随机判定体验。

## 为什么做这个

传统 TRPG 判定依赖骰子（d20、d6 等），结果只有"成功/失败"二元判定，缺乏叙事张力。神谕卡牌（Oracle Deck）是《Ironsworn》《Thousand Year Old Vampire》等独立 TRPG 中流行的判定机制——它给出"肯定/否定/中性"三级结果，并附带叙事性描述，让随机事件自然融入故事。

本工具将这一机制数字化：输入问题，抽取神谕，获得带有叙事描述的判定结果。核心巧思在于**命运倾向系统**——连续的结果会累积命运权重，影响后续抽牌的概率分布，模拟"命运"的惯性。

## 核心机制

- **三级神谕**：肯定（绿）/ 否定（红）/ 中性（金），每张牌附带叙事描述
- **命运倾向**：连续肯定或否定会累积命运值，后续抽牌概率随之偏移（±5%/点，上限 ±50%）
- **问题类型修正**：战斗/探索/社交/命运四类问题对三级结果有不同权重修正
- **加权随机**：每张牌有 1-10 的权重，权重越高越容易被抽中
- **自定义牌组**：支持编辑牌组内容（符号|名称|描述|权重），localStorage 持久化
- **历史记录**：自动保存最近 50 条判定记录

## 技术点

- 纯 HTML/CSS/JS 单文件，零外部依赖，file:// 直接打开
- CSS 3D 翻牌动画（perspective + rotateY + backface-visibility）
- localStorage 持久化牌组和历史记录
- 加权随机算法 + 命运倾向动态修正
- 响应式布局，深色主题，中文界面

## 怎么玩

1. 在文本框中输入你的问题（如"前方森林中是否有埋伏？"）
2. 选择问题类型（战斗/探索/社交/命运）
3. 点击"抽取神谕"，卡牌翻转显示结果
4. 点击卡牌可正反面切换查看
5. 观察命运倾向条的变化——连续同向结果会累积命运惯性
6. 在底部编辑自定义牌组，格式：`符号|名称|描述|权重(1-10)`
