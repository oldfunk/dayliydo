# 渗流阈值 · 团簇贯通

一个纯 HTML/CSS/JS 的单文件网页：每个格点按概率 p 随机被占据，相邻占据点连成团簇。把 p 推过临界线的那一刻，一条团簇突然从左边接到右边。双击 `index.html` 即可离线运行，零外部依赖、零网络请求。

12 月主题「临界现象 · 相变」第 3 件。

## 一、为什么做这个

12 月主题的脉络是：Kuramoto（第 1 件）证明有序能从耦合里自己走出来；伊辛磁畴（第 2 件）证明有序会在一条精确可算的线上消失；这一件换一个方向——**贯通这条线不是被画出来的，是团簇生长到自己接上的**。

二维方格 site percolation 的临界点数值是公认的：

    p_c ≈ 0.592746

而且开边界下方格在 p_c 处的**左右贯通概率恰好是 0.5**（自对偶性 + 90° 旋转对称）。这条解析结论给了本作一个极硬的验证凭证：扫描 P_LR(p)，它与 0.5 的交点应当落在 p_c 上。

同类作品（各类 percolation 玩具、HN 上的 critical cluster 演示）大多停在「拖 p 看团簇变色」。本作的差异化是**三条可验证凭证**：

1. **P_LR(p) = 0.5 的交点**就是临界点。实测 L=96 时 p* = 0.5925，与 p_c 差 0.0002。
2. **平均团簇尺寸 S 在 p_c 发散**，且有限尺寸下峰高按 `S_max ∝ L^(γ/ν)` 增长，理论 `γ/ν = 1.792`。实测 L=48/96/160 的峰高比给出指数 1.69。
3. **有限尺寸曲线收敛**：L=48/96/160 三条 P_LR 曲线随 L 增大变陡，并共同交于 p_c 附近——临界点是热力学极限的性质，不是某个尺寸的偶然。

## 二、核心机制与技术点

### 模型

- 二维方格，每个格点以概率 p 独立占据，最近邻四连通。开边界（不周期回绕）。
- 连通标记：迭代 DFS（显式栈，不用递归），一次遍历同时得到每个团簇的尺寸与触边标志，O(N)。
- 触边标志用位掩码：1=触左、2=触右、4=触上、8=触下。左右贯通 = `(f&1)&&(f&2)`，上下贯通 = `(f&4)&&(f&8)`。
- 平均团簇尺寸 `S = Σ s²n_s / Σ s n_s`（n_s 为该尺寸的团簇数）。若最大团簇贯通，则把它排除——它对应热力学极限里的无限团簇，排除后才是在两侧都发散的有限团簇平均尺寸。
- 确定性：mulberry32 种子 PRNG，占据与洗牌共用同一条随机流，同种子逐格复现。

### 测量

- **贯通概率曲线**：扫描 p ∈ [0.40, 0.80] 共 41 点，每点独立采样若干随机构型，统计 P_LR、P_TB、最大团簇占比、S。
- **实测 p\***：对 P_LR(p) 做线性插值，找跨过 0.5 的交点。
- **S 峰位 / 峰高**：S(p) 的极大值及其位置。
- **团簇尺寸分布**：当前 p 的 n_s 直方图（log2 s × log10 n_s），叠加斜率 -τ 的参考线。

### 实现要点

- **像素级渲染**：占据与团簇颜色直接写 `ImageData`（每格 1 像素），再 `drawImage` 关闭平滑放大到显示尺寸。零逐格绘制开销。
- **异步扫描**：`setTimeout` 分片推进，UI 不冻结；带进度条与停止按钮。
- **三尺寸对比**：一次连续跑 L=48/96/160，三条曲线叠加，直观看到曲线变陡、交点收敛到 p_c。
- **逐格揭示**：Fisher–Yates 洗牌后按随机顺序逐格显现，看团簇生长、合并、接通的完整过程（每帧约 1/120 格）。
- **点击涂擦**：点空格涂占据、点已占据处擦除，把团簇当作可操作对象；涂完立即重算连通标记。

### 验证结果（无头断言，29 项全通过）

`node selftest.js`：

- **极端**：p=0 全空、S=0；p=1 单一团簇占满全格且 S=0（唯一团簇贯通，没有有限团簇）。
- **确定性**：同种子同 p 逐格复现；换种子构型不同。
- **手动构型**：只占第一行 ⇒ 1 个团簇、尺寸 L、左右贯通不上下；只占第一列相反；两个分离方块 ⇒ 尺寸 {2,3}，直方图总数 = 团簇数。
- **临界凭证**：L=96、41 点、每点 200 采样 ⇒ p* = 0.5925，与 p_c 差 -0.0002；p_c 处 P_LR = 0.505。
- **发散**：S 峰高 L=48 → 150.3、L=96 → 448.5、L=160 → 1150.1；L=160/48 峰高比 7.65，标度指数 1.69（理论 γ/ν = 1.792）。
- **分形维数**：s_max / L^(91/48) = 0.422 / 0.430 / 0.420（L=64/96/160），近似常数。
- **幂律趋势**：L=256，尺寸分布斜率在 s=2–8 窗口为 -1.601，在 s=100–300 窗口为 -2.013，向理论 τ = 2.055 趋近（小 s 端存在交叉）。
- **性能**：L=96 单次标记 0.79 ms，满足实时交互预算。

**UI 冒烟**（`node _smoke_ui.js`，最小 DOM/Canvas 桩，14 项断言）：脚本执行、重新生成、p/L/采样数滑块、单尺寸与三尺寸扫描、清空曲线、跳到 p_c、随机种子、逐格揭示、画布涂擦、导出 PNG、连续 rAF 帧，全绿。

## 三、怎么玩

- **拖 p**：0.30–0.90。低于 0.55 只有碎点；0.59 附近盯着团簇突然接上；高于 0.62 一条金色团簇贯通全格。
- **逐格揭示**：按 `P`，看团簇从随机顺序里长出来、合并、接通。
- **扫描 p**：41 点自动采样，画出 P_LR/P_TB 与 S 曲线，直接读出 p* 与 S 峰位。
- **扫描模式**切到「L = 48 / 96 / 160 三条对比」：看三条曲线交于 p_c。
- **涂擦**：点击/拖动涂占据，再点已占据处擦除。
- **晶格 L**：32–160，越大曲线越陡、越贴近精确 p_c（有限尺寸效应）。
- **导出 PNG**：把当前构型存成图片。

操作：`空格` 重新生成 · `R` 随机种子 · `P` 逐格揭示 · `S` 扫描 · `C` 清空曲线。
