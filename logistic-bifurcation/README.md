# 混沌之门 · 倍周期分岔（logistic-bifurcation）

单文件、零依赖、零联网的混沌入门演示。双击 `index.html` 即可离线运行。

## 为什么做这个

「混沌」常被讲成一种只可意会不可言传的乱。这件作品想证明相反的事：
无序的门槛，恰恰是整个系统里**最可被精确测量的地方**。

一条只有三个字符的递推式 `x → r·x·(1−x)`，一根滑杆，就能看到：
稳定点一分为二、二分为四、四分为八……然后在某个精确的 r 值上突然碎成混沌。
而每次加倍之间的间距之比，会收敛到一个与系统细节无关的普适常数 4.6692…
——这不是画上去的注释，是页面上现场解出来的数。

## 核心机制 / 技术点

**1. 分岔图：吸引子的长相**
横轴 r、纵轴迭代稳定后的 x。每个像素列对应一个 r：先舍去 400 步暂态，
再取 260 步落点累加成密度，用 256 级调色板着色。逐列分批渲染（每帧 20 列），
于是图案是「长出来」的，不是一次性贴上去的。支持拖拽横向缩放、双击复位。

**2. 倍周期分岔点的现场求解（费根鲍姆 δ）**
对周期 `p = 2^(n−1)` 的轨道，先迭代落到吸引子，再用牛顿法把 x 精修到 `f^p(x)=x`
的不动点；随后二分搜索乘子 `(f^p)'(x)` 恰好降到 −1 的 r——那正是轨道失稳、一分为二的时刻。
实测 r₁…r₆ 对照文献值误差约 1e-8（耗时约 15 ms），间距比依次给出
4.7514 → 4.6563 → 4.6682 → 4.6687，逼近理论 δ = 4.669201609。
再外推得到混沌门槛 r∞ ≈ 3.5699457。

> 一个真实的坑：迭代种子若取临界点 0.5，在 r=4 时 `0.5→1→0` 会精确落进不动点，
> 于是 λ 被错算成 ln4 而不是 ln2、周期判定误报「周期 1」。改用非临界种子后消失。

**3. 李雅普诺夫指数：混沌的体温计**
`λ = 平均 ln|f'(x)|`（舍去暂态）。λ<0 收敛到周期轨道，λ>0 是指数分离即混沌。
曲线上 λ 首次翻正的位置正是 r∞；r≈3.83 的周期 3 窗口会让 λ 重新掉回负值——
混沌里嵌着的秩序孤岛。两个判据互相印证，不靠肉眼看图猜。

**4. 蛛网图：一次迭代怎么走**
抛物线 `y=f(x)` 与对角线 `y=x` 同屏，从 x₀=0.2 出发竖直撞曲线、水平回斜线，
动画逐帧画出轨道的命运；旁边实时读出周期、λ 与舍去暂态后的轨道数值。

## 怎么玩

1. 拖 r 滑杆（或点「周期 2 / 4 / 8 / 16 / 边缘 / 周期 3」预设），看蛛网如何定型、分叉、碎裂。
2. 在分岔图上拖选一段 r 放大，肉眼数出加倍序列；双击回到全景。
3. 对照右侧现场实测的 δ 表：前两行还离得远，到 δ₄ 已经贴住 4.6692。
4. 在李雅普诺夫图上确认：λ 翻正的横坐标与分岔图里那片「碎成噪点」的起点重合。
