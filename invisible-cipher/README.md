# 零宽密信 · 隐形文字隐写工具

一个零依赖、可离线运行的「文字隐写」小工具：把秘密消息用肉眼不可见的零宽度 Unicode 字符编进任意载体文字里，复制出去时外表毫无变化，但接收方粘贴即可还原。可选密码（纯 JS 实现 SHA-256 + 流密码，离线可信）。

## 核心机制
- 用 4 个零宽 Unicode 字符当「墨水」：`U+200B/U+200C/U+200D/U+2060` 分别映射二进制 `00/01/10/11`。
- 帧结构：`起始哨兵 + 16 位零宽长度头 + 载荷`，长度头让解码端精确截取、彻底避免载荷内字符与哨兵碰撞。
- **明文模式**：直接编码（肉眼可见载体文字、密文完全隐形）。
- **加密模式**：消息先拼接 SHA-256 校验和，再用密码派生的密钥流（基于 SHA-256 的流密码）逐字节异或，最后做零宽编码；解密端校验和不匹配即判定「密码错误 / 密文损坏」。
- 全程纯 JavaScript，不调用任何浏览器加密 API，`file://` 双击即可用。

## 玩法
1. 「加密隐藏」页：填载体文字（可留空）、秘密消息、可选密码 → 点「生成密信」→ 复制结果。
2. 「解密检测」页：把任何可疑文字粘贴进来，点「扫描并解密」，显形视图会以高亮标出隐藏字符位置，并显示零宽字符总数与本工具载荷是否存在。
3. 同一密文有人发给你、你粘进解密页、输对密码即可还原；无密码的明文密文无需密码。

## 用途与边界
- 适合演示「隐写」原理、在公开文本里夹带私密注记、学习 Unicode 不可见字符。
- 仅为学习与研究用途；密文虽肉眼不可见，但并非加密意义上的「安全」——知道方法者即可扫描还原（除非启用密码，但密码强度决定安全性）。
