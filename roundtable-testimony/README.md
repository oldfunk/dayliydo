# 圆桌证词 · Roundtable Testimony

罗生门推理台 · 其三。墨园晚宴，六位客人围桌而坐，窗边那把椅子属于最后离开书房的人。
六份供述摆在桌上——**句句为真**，但人人只见自己眼前的一方。

## 为什么做这个（设计意图）

前两作（真相账本、不在场证明）解的分别是「证词与证词的矛盾」和「证词与物理世界的矛盾」。
本作收束整个系列：**这里没有人撒谎**。矛盾不来自谎言，来自视角的局部性——
每个证人只看得见圆桌的几条边，你解的从来不是谎，是每个人看不见的那半边圆桌。

市面上逻辑网格题（zebra puzzle）的解法都是「静态线索 + 求解器」，答案在机器里。
本作把求解器拆给玩家：约束就在屏幕上，亲手安放席位，灯亮灯灭即时反馈——
**推理过程本身就是玩法**，不是提交答案等判定。

## 核心机制 / 技术点

1. **座位排列约束题，生成器保证唯一解**
   六人圆桌共 6! = 720 种排列。生成器随机取一个「真相排列」，
   收集该排列下为真的全部供述，贪心加入能收紧解空间的供述；
   贪心停滞时（剩余解构成旋转对称族，单条供述无法区分）启用救援：
   任取一个非答案解，找一条「对答案成立、对它不成立」的真供述，必然砍掉该解。
   最终经全量穷举验证：满足全部供述的排列**恰好唯一**——所以灯全绿 = 你解出了真相，
   不存在「蒙对」或「多解」。

2. **旋转对称性的破除（本作最大的坑）**
   相邻/隔位/对面/左右手/不相邻这五种关系全部是**旋转不变**的——
   整桌人集体转一个座位，所有供述依然成立，解数永远 ≥ 6。
   必须引入绝对锚点：「某人坐在『壁炉』席位」这类命名席位约束才能打破对称。
   窗边席位刻意不进题面，留给通关揭晓时的叙事锚点。

3. **实时证词热力**
   每次安放席位，六条供述即时重估：绿 = 与当前席位吻合，红 = 矛盾，灰 = 尚待安置。
   玩家移动一个人，看见的是整组约束的连锁反应——错放一人，可能亮起三盏红灯。

4. **推演提示 = 可能性收缩**
   提示按钮把玩家「当前已认可（未亮红灯）的供述」代入穷举，
   算出某位客人在所有不矛盾世界里的可能座位，在圆桌上以虚线金圈标出——
   这是把求解器的一部分能力借给玩家，而不是直接给答案。

5. **零依赖单文件**
   纯 HTML/CSS/JS，无 CDN、无网络请求、无构建；双击 `index.html` 离线即玩。
   进度（关卡数）存 localStorage，`file://` 下不可用时自动降级。

## 怎么玩

1. 点下方角色池的一位客人（或直接拖拽），再点圆桌空位入座；
   点已入座者可请其离席；Esc 取消选择。
2. 读右侧六份供述，把它们当成约束推演。注意界面提示：**顺时针即为左手边**。
3. 绿灯 = 这条供述与当前席位自洽；红灯 = 矛盾（供述不会错，错的是座位）；
   灰灯 = 涉及的客人还没安置。
4. 卡住时点「推演提示」：系统标出某位客人按当前认可供述的所有可能席位。
5. 六灯全绿（或点「呈堂证供」确认）即破案：窗边席位揭晓，案件叙事展开，
   可继续下一案——关卡越高，供述越多（4 → 6 条），补白的冗余真供述让题面更耐猜，
   但解始终唯一。
