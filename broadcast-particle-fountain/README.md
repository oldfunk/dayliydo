# broadcast-particle-fountain — 跨标签粒子喷泉

`broadcast-constellation` 的姊妹篇，**同一 Broadcast Channel API，完全不同的同步模式**。

## 核心机制：确定性事件溯源模拟

- **只广播「发射事件」**：点击位置、时间戳、颜色索引 —— 极小载荷
- **各标签页运行相同确定性物理引擎**：重力、阻力、生命周期、轨迹均为纯函数 `f(state, dt) → newState`
- **零位置同步流量**：不发送每帧坐标，接收端按时间戳快进模拟到「当前帧」
- **鬼影光标**：远端发射点以衰减十字准星显示，直观展示「别人在哪里点击」

> 这是 `broadcast-constellation`（状态广播：全量星图同步、合并去重）的**对偶模式** —— 事件溯源 vs 状态同步，同 API 两种范式。

## 玩法

1. 打开 `index.html`，点击/拖拽画布发射粒子
2. 新标签页打开同一文件（`file://` 或同源 HTTP），自动连接
3. 在任一标签发射，所有标签**同步呈现**相同粒子轨迹
4. 观察鬼影光标：其他标签的发射点会以发光十字短暂显现
5. 键盘：`1-6` 切色、`C` 清空本视图、`R` 重置全网（需确认）

## 与前作的承继关系

| 维度 | broadcast-constellation | broadcast-particle-fountain |
|------|------------------------|----------------------------|
| 同步模式 | 状态广播 + 合并去重 | 事件溯源 + 确定性重放 |
| 视觉隐喻 | 静态星座、命名、连线 | 动态粒子、重力、轨迹、鬼影 |
| 数据流 | 双向全量/增量星图 | 单向发射事件（幂等） |
| 存储 | localStorage 持久化星图 | 仅保存配色，**粒子易失**即特性 |
| 核心巧思 | Broadcast Channel 做「共享数据库」 | Broadcast Channel 做「确定性时钟同步」 |

## 技术细节

- 单文件 `index.html`，零依赖、零 CDN、离线可用
- `file://` 协议下多标签同源即可通信（同 `broadcast-constellation`）
- 物理参数：重力 `0.18`、阻力 `0.992`、基础寿命 `180帧`、单次发射 `18粒`
- 广播节流 `30ms`，心跳 `3s`，鬼影光标寿命 `120帧`
- 调色盘 6 色：暖色系（琥珀/橙红/深红）+ 冷色系（青绿/紫罗兰/冰蓝）

## 设计意图

「把 Broadcast Channel 当作**分布式确定性时钟**而非共享数据库」——这是本系列的第二种范式。第一作展示「数据同步」，第二作展示「模拟同步」。两者合观，即见该 API 的两种根本用法。
