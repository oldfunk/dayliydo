# 同步相变 · 序参量

一个纯 HTML/CSS/JS 的单文件网页：几百个振子各自为政，只跟邻居交换相位差的正弦。把耦合 K 推过解析临界线 Kc=2γ 的那一刻，无序相突然塌缩成有序相。双击 `index.html` 即可离线运行，零外部依赖、零网络请求。

12 月主题「临界现象 · 相变」第 1 件。

## 一、为什么做这个

11 月的「涌现图案 · 局部规则」做到第 4 件（沙堆）后已经收束：那些作品都在证明"图案能从局部规则里长出来"。12 月往下推一层——**临界**。临界现象的特别之处在于：有序相不是被设定出来的，系统自己走过去，然后在某条线上突然跳出来；而那条线是可以从局部规则解析预测的。

Kuramoto 模型是这件事最干净的入口，规则只有一行：

    dθᵢ/dt = ωᵢ + (K/N) · Σⱼ sin(θⱼ − θᵢ)

振子只感受邻居的相位差正弦，没有任何一处代码知道"同步"长什么样。但当代入频率分布后，临界耦合有闭式解：

- 洛伦兹分布 g(ω)=γ/[π(ω²+γ²)] → **Kc = 2γ**
- 高斯分布（宽度 σ） → **Kc = 2√(2/π)·σ**

同类作品（HN 上的 kuramoto.dev、templetwo 的振荡器可视化、vercel 的 Ising 模拟器）大多停在"拖参数看动画"。本作的差异化是**把临界线变成一条会被扫描验证的凭证**：页面实时画出序参量 r 随 K 的曲线，黄色虚线是解析 Kc，你亲手把 K 推过去，看 r 在曲线上的哪一点跳起来。

第二个反直觉的点给了本作另一半价值：**拓扑决定同步**。把全连接换成纯环（只跟左右邻居耦合），同样局部规则、同样 K，r 从 0.92 掉到 0.11——一维系统没有长程序，局部耦合根本锁不住。加两条随机长程边（小世界），r 又跳回 0.92。同步能力不是振子的性质，是**连接结构**的性质。

## 二、核心机制与技术点

### 规则与积分

- 相位 θᵢ ∈ [0, 2π)，本征频率 ωᵢ 从分布采样（种子驱动，可复现）。
- 耦合项用 **序参量的 O(N) 形式**：Σⱼ sin(θⱼ − θᵢ)/N = r·sin(ψ − θᵢ)，其中 r·e^{iψ} = (1/N)Σe^{iθᵢ}。全连接因此从 O(N²) 降到 O(N)，N=800 也不卡。
- 积分用同步更新的欧拉法（先算全部 dθ 再统一推进），dt=0.02，避免"边算边改"的伪耦合。
- 拓扑三选：全连接（平均场）/ 小世界（环最近邻 + 每人 2 条随机长程边）/ 纯环（一维周期边界）。
- 序参量 r = |(1/N)Σe^{iθᵢ}| ∈ [0,1]：r≈0 无序，r≈1 完全锁相。

### 实现要点

- **确定性**：频率采样、初始相位全走同一种子 PRNG（mulberry32 + Box-Muller）。系统无噪声、无随机力，同种子逐格复现。这使"推过临界"成为可复现实验而非抽奖。
- **拖尾渲染**：环区每帧以低透明度覆盖，振子轨迹自己拖成弧；同步时整圈颜色连续成一条彩虹波，无序时是杂点。
- **r-K 曲线**：扫描模式每帧推进 K 并积分，把 (K, r) 落到曲线上；升支/降支各一条，用于看转变位置。
- **双峰簇同步**：频率取 ±γ 两群时，系统锁成两个相位簇——相位分布直方图上出现两个分离的峰。单峰分布作对照，保持单一连续团。
- **频率/相位双直方图**：实时对照"本征频率分布"与"当前相位分布"，簇结构一眼可见。
- **诚实标注有限尺寸**：N 有限且从随机相位出发时，实测转变点会略高于热力学极限的 Kc。页面同时显示解析 Kc 与当前 K/Kc，不假装二者重合。

### 验证结果（无头断言，23 项全通过）

`node selftest.js`，模型层 + 视图层共 23 项断言全绿，耗时约 32 秒（ARM 单板机）。关键数据：

- **解析临界对照**：洛伦兹 γ=0.5 的解析 Kc=1.0。N=256、每点 1400 步扫描——
  `K=0.8→r=0.117  1.0→0.241  1.2→0.450  1.4→0.573  1.6→0.652`
  有序相从 K=1.0 开始出现，与解析值吻合。
- **无序相**：K=0、N=400 时 r=0.018（理论 r ~ 1/√N = 0.05 量级）。
- **锁相相**：高斯 γ=0.5、K=8、N=400 时 r=0.998。
- **O(N) 技巧正确性**：序参量形式与直接双重求和的最大偏差 **1.8e-16**。
- **序参量自洽**：Σ sin(ψ−θᵢ) = **-6.4e-15**（ψ 定义的直接推论）。
- **双峰簇**：双峰分布下相位直方图分裂为两段（304 + 296），单峰对照为单段 600。
- **拓扑对比**：同一 K=2、同一高斯频率下，小世界 r=0.920，纯环 r=0.113。
- **确定性**：同种子两次运行 300 步后相位逐格完全相同（max|Δ|=0）。

## 三、怎么玩

- **推过临界**：点「推过临界」，K 自动从当前值升到 4，r-K 曲线同步画出升支。盯着黄色 Kc 虚线，看 r 在哪里突然抬头。
- **退回无序**：反向扫描，看系统如何失去相干。
- **耦合 K**：手动拖动，配合右侧实时统计里的 K/Kc 比值。
- **频率宽度 γ**：决定临界线位置（Kc=2γ）。γ 越大，越难同步。
- **频率分布**：洛伦兹单峰（有解析 Kc）/ 高斯单峰 / 双峰（簇同步，无解析 Kc）。
- **耦合拓扑**：全连接 / 小世界 / 纯环。切到纯环再推 K，看 r 怎么都上不去；换小世界立刻锁相。
- **初始条件**：随机相位（无序出发）/ 近同步（有序出发）。
- **振子数 N**：50～800。N 越大，转变越接近解析 Kc（有限尺寸效应）。
- **导出 PNG**：把当前环、r-K 曲线与两个直方图存成图片。
- **快捷键**：`空格` 暂停/继续，`S` 单步，`R` 按当前种子重建。
